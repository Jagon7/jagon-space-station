# 換股預估：選用的授權資料（可不放）

公開資料版預設不需要這兩個檔。若你有授權資料，放進來後 0050／0051／0056 的計算就會跟原本 TEJ＋FTSE＋LSEG 試算表完全一致：

| 檔名 | 欄位（UTF-8 CSV，第一欄代號） | 取代 |
|---|---|---|
| `ftse_iw.csv` | `代號,InvestabilityWeight` | 公開版用「1 − 董監持股」當公眾流通量 |
| `ibes.csv` | `代號,DPS1,DPS2,分析師家數` | 公開版用「近四季現金股利 ×(1+累積 EPS 成長率)」當預估股利 |

授權資料請確認你的授權允許放進這個 repo（公開 repo 會被所有人看到）。
